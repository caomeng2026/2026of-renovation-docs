# office-renovation-docs

办公用房维修项目初步设计文档生产线——**脱敏版**脚本与格式规则存档。

## ⚠️ 重要说明

- 本仓库所有内容已经过脱敏处理：真实项目名称、建设地点、建设单位名称一律以代号形式出现。
- **代号与真实项目的对照表只存在于本地，不放入本仓库。**
- 本仓库的定位是**模板骨架与规则沉淀**：脚本中的版式逻辑（封面、页码三节、自动目录、字体、进度表）是可复用资产；项目数据部分需在本地原件上操作，不要直接用本仓库副本生成正式文档。

## 目录结构

```
├── rules/
│   ├── format_rules.md   # 版式规则总纲（封面标准、标题段落格式、分页与目录规则）
│   └── SKILL.md          # 文档制作技能说明
└── scripts/
    ├── gen_zx_zt_doc.py          # [代号 ZX] 主楼初步设计生成脚本
    ├── gen_lz_doc.py             # [代号 LZ] 初步设计生成脚本
    ├── gen_lz_shenpi.py          # [代号 LZ] 申报审批模板生成脚本
    ├── gen_lz_add_fjp.py         # [代号 LZ] 附表补充脚本
    ├── replace_lz.py             # [代号 ZX -> LZ] 项目数据批量替换脚本
    ├── update_cover_2projects.py # 双项目封面格式批量修正
    └── update_fgx_gai_suan.py    # [代号 FGX] 概算金额更新脚本
```

## 版式规则要点（详见 rules/format_rules.md）

- 全文仿宋_GB2312（ascii/hAnsi/eastAsia/cs 全字符集）
- 封面：主标题 26pt 加粗居中，"设计单位"行两端对齐 + 首行缩进 4 字符、冒号后留 16 个全角空格
- 编制时间固定"二〇二六年八月"
- 页码：封面/编制说明不编页码，目录页起为第 1 节，页脚"第XX页/共XX页"（SECTIONPAGES 域）
- 每章另起一页（Heading 1 前插分页符段落）；目录为真实 Word 自动目录（TOC 域）
- 数量类数据统一保留小数点后 2 位
- 第八章 8.2 后必插 6 行 × 3 列进度安排表，工期三处一致

## 使用约定

- 改格式 → 改脚本 → 重新生成，不在 docx 上直接改
- 每次结构性改动先 commit，出问题回退
- 段落级文本替换必须用正文独有特征串匹配，禁止用章节标题串（会把标题覆盖成正文）
